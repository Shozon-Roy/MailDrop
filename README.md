# MailDrop - Temporary Email Generator

MailDrop is a temporary email generator website designed for quick, anonymous email address creation. Built with **React**, **TypeScript**, **Next.js**, **Tailwind CSS**, **Material UI Icons**, and powered by the Temp Mail API, MailDrop makes it easy to receive emails without using your personal address.

> **Live Demo:** [https://promaildrop.vercel.app/](https://promaildrop.vercel.app/)

## 🚀 About

MailDrop is a sleek, privacy-focused temporary email generator that allows users to create disposable email addresses instantly. Built with modern web technologies, it provides a secure and user-friendly solution for avoiding spam and protecting your primary email address.

---

## ✨ Features

- 🔥 **Instant Temp Email Generation:** Create a disposable email address in one click.
- 📥 **Real-time Inbox:** View and refresh incoming emails instantly.
- 💌 **Email Details:** Read full email content, including subject, sender, and attachments.
- 🧹 **Easy Cleanup:** Delete your temp email address anytime.
- ⚡ **Modern UI:** Responsive design built with Tailwind CSS & Material UI Icons.
- 🛡️ **Privacy First:** No login or personal data required.
- 🌐 **Powered by Temp Mail API:** Reliable, secure email delivery.
- 🎨 **Preview Image:** See what the app looks like (see above).
- 🚀 **Live Demo:** Test it out at [https://promaildrop.vercel.app/](https://promaildrop.vercel.app/).

## 🛠️ Tech Stack
