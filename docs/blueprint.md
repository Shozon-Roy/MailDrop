# **App Name**: MailDrop

## Core Features:

- Address Generation: Generate a unique, temporary email address.
- Address Display: Display the temporary email address prominently for easy copying.
- Inbox View: Provide an inbox interface to view received emails.
- Auto Refresh: Automatically refresh the inbox to display new emails.
- Expiration Timer: Set a timer to expire the email address after a certain period.
- Spam Filter: Use an LLM as a tool to filter out potential spam emails based on sender reputation or content analysis.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB), evoking trust and reliability.
- Background color: Light gray (#F0F0F0), offering a clean, uncluttered feel.
- Accent color: Soft lavender (#E6E6FA) to highlight important actions.
- Body and headline font: 'Inter', a sans-serif font that offers a modern, machined, objective, neutral look, suitable for both headlines and body text.
- Simple, clean icons to represent email actions (e.g., delete, refresh).
- Clean and intuitive layout, focusing on ease of use and quick access to emails.
- Subtle animations on email arrival or deletion.
